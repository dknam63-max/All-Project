### 추가 검증
- **자막 글리프**: 사용된 54개 고유 문자 전부 Noto Sans KR Bold cmap에 존재 — 두부(□) 렌더 없음
- **자막·배지 실렌더 확인**: 6개 씬 전 구간에서 자막 밴드(y 1320–1450)와 배지 밴드(y 250–400)의 잉크 픽셀 검출
- **나레이션 정확도**: faster-whisper(ko) 역전사로 6개 트랙 전부 대본과 일치 확인
- **라우드니스**: `loudnorm I=-14 TP=-1 LRA=11` 적용, 측정 True Peak **-1.0 dBFS**

## 남은 작업 (편집 단계에서 반드시 처리)

1. **BGM · 효과음 삽입** — 기획서가 "상업용 라이선스 음원만"을 요구하고, 이번에 쓴 생성 도구는 독립 음악/효과음 생성을 지원하지 않아 **오디오는 나레이션만** 들어 있습니다.
   - 기둥 F 고정 1곡(밝고 정돈된 라이프스타일 팝)을 얹고
   - 나레이션 기준 **−12~−15dB 덕킹**, CTA 구간(28~32초) 볼륨 다운
   - 효과음 3개: ① 줄자 촥 · ② 매트 촤르륵 · ⑤ 사이즈 배지 팝
   - BGM을 얹은 뒤 최종 −14 LUFS / 피크 −1dBTP로 다시 노멀라이즈
2. **도면 그래픽** — 기획서 씬⑤의 "도면/수치 오버레이" 중 **수치 배지만** 구현했습니다. 도면 일러스트가 필요하면 추가하세요.
3. 최종본 육안 검수 후 Drive `영상6` 폴더 업로드 및 업로드 채널 게시.

## 해석 결정 (기획서 내부 충돌 처리)

기획서 3항의 자막 지시가 서로 충돌합니다.
- "하단 중앙(화면 아래 15~20% 지점)" → y 1536~1632
- "안전영역: 하단 25% 침범 금지" → y 1440 이하만 허용

쇼츠 UI가 하단을 덮는 점을 고려해 **안전영역을 우선**했고, 자막을 하단 25% 경계 바로 위(MarginV 480px, 하단에서 25%)에 배치했습니다. 하단에 최대한 가까우면서 UI에 가리지 않는 위치입니다.
